# Hussen Basha — Developer Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or package installation are required.

## Customize
- Update text and links in `index.html`.
- Change colors, spacing, and layout in `style.css`.
- Update navigation behavior in `script.js`.

## Publish
You can deploy this folder with GitHub Pages, Netlify, or Vercel.

## Notes
The content is based on the resume image supplied in the conversation. Add verified source-code links, a downloadable PDF resume, and any additional work samples before publishing.
